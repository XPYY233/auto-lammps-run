# 已回收原始数据的 AI 后处理

任务详情的“分析已回收原始数据”复用同一原始下载与模型连接。用户选择原作业、输入问题，
应用 AI 在强制阶段 Adapter 下读取已核验的完整数值文本，结合该角色允许的方法证据，
给出声明式分析方案。普通科研计算不会取得作者参考结果、论文答案或作者代码。

受信工具检查解析列、单位声明、来源引用及计算依赖，执行明确的逐行算术、统计、
直方图或线/散点图，并保存全部派生 CSV、PNG 和完整数值报告。仅支持工具公开的
完整容量；不截断、补点、丢弃异常行或新增物理计算。原始数值标量必须引用来源行，
不能从模型文字复制常量。出处逐字匹配不证明列含义、单位或科学方法正确。

作者参考 A 与普通科研复用这条入口。只有 A 可取得其关联论文的方法来源，仍保留原
调度终态、部分覆盖和失败；有图或后处理完成都不等于科学复现通过。原始及派生存储
追加到原作业账本，不创建 HPC 提交或返还机会。

同一问题最多三版，修订收到完整上一版和具体检查反馈。未知供应商调用阻断换编号
重发；确定收到的有效方案遇绘图、存储等技术故障，可恢复原执行并复用原付费答复。
原始字节、来源、连接、请求正文及产物摘要均须重新核对；读取历史不会调用模型。

本功能的离线、固定安装与真实用户按钮验收分别记入进度和私有回执。仍需按 P 目标核对
A/B 物理范围、单位与原文数据；本工具不单独判定科学通过或完成三篇 PAB。
