# 执行前选择复现目标

论文复现先列出所有图、子图、表格及补充图，逐项关联工况、源码/势函数/结构、
输出、采样、分析方法、比较标准与缺项，再由用户集中选定范围。相同工况的图表
共用同一计算；跨工况先拆分任务，不按图数多次提交或混入候选试错。

参考端复用文献工作台产物，经 `TaskStore.import_target_inventory` 导入完整评估。
每个条目需要来源位置，清单保存提取产物摘要。结构校验不代表科学含义已被验证。
目前首篇由开发端依据已有提取、原文和输出审计；通用参考 API 自动产生完整清单
尚未接线，不能宣称自动全文识别已完成。相关 API 接线由 harness 协作实施。

网页展示每项的可用性与限制，允许选择目标并说明排除范围。清单更新即清除旧选择；
旧修订保留。新冻结的复现任务必须已有目标选择，所选项目不能缺资源/比较标准，
不能把资料参数表计为模拟输出。此入口每个任务仍仅一个物理工况，跨工况阻止冻结。
这些是前置检查，不等于分析实现或科学结果通过。

完整清单、所选和排除项、分析口径、两次提交规则随同条件进入既有不可修改的冻结记录。
参考包保留计划；B 任务草稿不包含论文标识、图注、结果或评分标准。正文任务条件仍需
既有语义与允许资源审查，不能仅凭字段删除宣称盲测。参考复现仍保留独立释放/隔离入口，
普通研究自动执行入口不会因为此改动接受未审查的复现包。

已冻结的历史任务和首次基准验收保持原样，不追加伪造的事前计划。新增的全篇覆盖审计
与后处理只记为事后诊断。已有结果的重绘不增加模拟次数，也不追授新工况运行权限。

已验证：合成持久化/HTTP选择、无计划冻结拒绝、缺项拒绝、跨工况拒绝、选择失效、
历史不可改、参考信息不进入B草稿。完整自动提取、模型执行计划与评分器的逐目标绑定、
多工况批量编排仍未完成；本功能不能单独作为“目标先行全流程完成”的声明。

目标选择同时绑定选择时的全部条件证据摘要。材料、工况或条件依据改变时，在同一修订
中清除旧选择；历史选择仍保留，新条件需要重新确认目标范围。此绑定防止无提示漂移，
不代表已自动证明目标描述与条件语义一致，也不替代执行输出和评分器的逐项接线。

已完成任务的结果页以图形为主：同一份核验报告可声明图表主题，将原文图片、作者运行、
独立运行及对应CSV预览编组。客户端不按论文编号猜测科学对应关系，不把报告外文件展示为
证据。P/A/B在每个对照页面就地解释，表头使用全称；38项覆盖清单按需展开。
主题编组只决定展示，不改变指标、验收、运行次数，也不代替新任务的目标选择/冻结。

结果展示规范补充：每组图表就地标明 P（论文结果）、A（作者源码运行）和 B（Agent独立生成），
用全称、大号字母及来源底色共同区分；A使用深蓝、B使用紫红，不能只靠颜色。类别/元素的
科学配色在两份图中保持一致。原文图、正式比较与事后追加分析必须分清，追加分析注明
方法、采样与原图的差别，不增加通过项。先展示实际图与带单位数值表，再按需展开审计。
图片相同时核验真实文件和原始数据来源，在界面显式说明相同；不得换色制造差异或以
文件相同推断科学通过。标记不改原始证据与下载字节，具体相同原因随来源审计记录。

## 选择时的准备状态

目标选择界面现在直接显示选中数量、工况组和全部缺项。只读预览复用冻结前同一组检查：
未选目标的范围说明、资源、比较标准和确认条件。跨工况仍须拆分后才能进入单轮评测；
不自动删减目标以制造就绪。修改后须重新保存，较晚返回的旧检查不能启用冻结按钮。
这不等于通用全文自动提取或逐目标执行/评分已经完成。

## 文献复用与普通 B 流程

优先直接复用既有文献工作台的正文、身份、图表定位、表格结构及来源产物，
不重新实现整套文献解析。新增部分限于真实缺项的适配、数值数字化与 PAB 导出；
保留自动提取失败和人工校正，不能把它们描述为全自动成功。已有模块调用记录与
版本摘要属于参考证据，复用不等于已经完成可独立分发的应用集成。

原文分别产出结果 P 和不含答案的科研条件提示词。只有允许条件、初始输入和势函数
进入 B；正文中的目标值、作者方案代码与专用分析答案留在参考端。B 使用普通用户
页面与配置的模型 API，从需求理解、建模、方案到 HPC 提交、自动跟进、回收原始
输出、分析、可视化和报告全程运行。不得由开发者后台补步骤或私有论文脚本替代。
