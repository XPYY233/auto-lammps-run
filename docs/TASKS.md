# 任务条件确认

PR 2 提供真实持久化的本机网页流程：输入需求 → 核对来源与缺项 → 解决矛盾 → 明确确认 → 冻结条件 → 导出审阅记录。关联 [Issue #9](https://github.com/XPYY233/auto-lammps-run/issues/9)。没有演示计算状态、目标模拟或模型调用。

## 启动

Python 3.11+，建议使用独立虚拟环境。安装网页和测试依赖后，从项目目录运行：

```sh
python3 -m pip install -e '.[web,test]'
python3 -m auto_lammps.web --data-directory "$HOME/.local/share/auto-lammps-private/workbench" --port 8785
```

访问 `http://127.0.0.1:8785/`。数据目录必须在 Git 外且仅本人可访问。端口被占用时使用另一个未占用端口，不停止其他应用。服务只绑定本机回环地址；当前是单人开发入口，没有多人认证或生产部署承诺。浏览器关闭后记录仍保存在私人 SQLite 中；再次启动同一目录即可继续。电脑休眠或服务退出后页面不可用。

## 条件与来源

保留完整原始需求。确定性整理仅识别“字段名称：条件值”这样的独立行，字段名称与页面一致；重复标签保留多份证据。普通自然语言不猜填。此入口不能代替仍未接通的模型条件提取。

20 类条件覆盖验收范围、论文标识、材料、初始结构、尺寸晶向、边界、缺陷加载、势函数版本、单位制、温压、系综、步长、阶段、初始化种子、采样输出、目标物理量、分析和资源。适用性需要明确；不适用要说明原因，核心字段及复现模式的论文标识不能跳过。必要性尚未针对具体任务家族精细化。

来源分为用户、论文、作者代码、建议；未填写保持缺失。论文和代码需要来源位置。声明为结果而不是输入的证据会被拒绝，但这不是语义级防泄漏检验：任意自由文本仍需核实，不能通过字段标签证明其科学正确或不含答案。

新增证据撤销该字段的旧确认。不同 value/unit/applicability 组合触发待解决矛盾，需要明确选择及理由；旧证据不删除。完全相同的文本条件可保留不同来源，但仍需重新确认。本版不自动换算单位，也不判断两段文字是否物理等价，不做跨字段科学约束验证。

修改携带明确版本号，事务内核对，过期页面不能覆盖较新的记录。每次修改、选择、确认和冻结追加不可覆盖的历史。冻结要求全部字段已确认；之后禁止修改，不提供通过复制/重命名重置正式评测的接口。

## 导出与执行边界

`conditions_frozen` 只表示用户确认的审阅记录已锁定。导出包含原始描述、全部候选、来源、选择理由与确认状态，并明确 `scientific_validation=not_performed`、`execution_authorized=false`。`record_sha256` 校验这份审阅记录；它不是正式评测任务身份，不应直接用于账本注册或重置提交额度。

这份导出仅给受信操作者审阅，**不是主 Agent 任务包**：作者代码位置及其他来源仍可能暴露目标信息。主 Agent 包与独立参考/评分资料的分离、实际系统权限隔离、科学参数类型化、结构与势函数兼容检查和执行许可仍需独立实现。网页没有 shell、SSH、模型或提交端点，冻结不会产生任何计算。

## 验证

离线测试覆盖无隐含默认值、明确标签提取、冲突使确认失效、理由要求、来源缺失、结果证据拒绝、并发旧版本、数据库重开、冻结不可改及导出摘要。ASGI 测试使用真实请求和私人临时数据库，覆盖 Host/Origin、请求大小、错误响应和静态资源。

已在本机浏览器实测建立任务、填写/确认、冲突撤销、刷新恢复、解释选择、真正停止并重启服务、冻结和下载。合成夹具明显标记为软件验收；一轮完整流程还通过页面输入 20 条标签并逐项点击确认。合成记录不计作科研成果。独立环境安装网页依赖并通过测试；Linux CI 以 PR 当前版本为准。

网页使用本地静态资源、纯文本 DOM 渲染、禁止缓存与跨站嵌入；POST 要求同源及固定自定义头，防止普通跨站网页代发请求。这不取代多人服务的身份认证。本版任务列表展示最近 200 条，完整记录仍可通过原任务地址访问；尚无检索/分页界面。

框架接口依据：[FastAPI 入门](https://fastapi.tiangolo.com/tutorial/first-steps/)与[官方测试说明](https://fastapi.tiangolo.com/tutorial/testing/)。没有复制旧工作台受限源码。
