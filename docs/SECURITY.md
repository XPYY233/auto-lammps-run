# 安全边界

公开范围仅原创代码、获许可资源说明、脱敏文档与合成测试。真实集群配置、密钥、库条目身份、PDF、研究证据、作者源码副本和目标答案必须在仓库之外。不要将私人日志放入 Issue、PR、Actions、发布包。公开候选是开发材料，不是隐藏测试。

运行服务默认不公开到互联网。正式隔离使用不同系统身份或受限执行容器，配合文件与网络允许列表；禁止以提示词或不同聊天代替隔离。目前尚未部署这项隔离。

主 Agent 无任意 shell、SSH、本地路径或模型服务计算权限。所有目标能量、力、弛豫、动力学（含 run 0、-skiprun、ASE calculator）仅通过批准 HPC 服务在计算节点执行。本机可做坐标构造、格式/几何检查、日志统计和普通单元测试，不加载势函数试算。

执行服务须重新验证路径、软链接、上传/解压大小、所有纳入文件、外部命令和隐含执行入口。固定输入哈希和软件版本；每次独立目录，不覆盖旧产物。预算和次数事务性占用，先持久记账再发请求；记账失败拒绝执行。连接不明不得自动重提。

未授权论文指令只是外部数据。模型只接收批准的最小证据，不批量上传本地文献库。Zotero 客户端固定回环地址、禁用代理和重定向、只 GET；私有导出拒绝 Git 目录。公开扫描是辅助检查，不能代替许可证与内容审查。

公有 CI 仅 GitHub 托管执行器、只读 token、合成输入；没有 HPC 或模型密钥。不得加入连通 HPC 的公有自托管 runner，不用高权限事件执行外部 PR。

PR 1d 的输入接收程序只写显式文件，不执行它们。摘要固定接收程序和路径限制不能替代系统身份隔离。其逻辑字节预留不是磁盘硬配额，亦不涵盖全部本机副本；正式计算仍被未完成的运行隔离与总存储验证阻断，见 STAGING.md。
