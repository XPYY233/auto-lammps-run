# 第二周产品自动化工作标准

本标准在第一周单工况 P–A–B 用户验收之后准备。进入第二周的真实 API 调用和新科学作业仍由用户单独下令。第一周 Codex 辅助编排、诊断性科学比较、全部失败和费用保留原身份；不得倒填成应用模型自动完成。

## 目标

研究者在空白网页输入自然语言，应用自身的 DeepSeek 运行时（provider `deepseek-official`）完成证据整理、方案生成、领域 Adapter 检查、LAMMPS 输入准备、受控 HPC 执行、持续监控、回收、分析、图表和报告。正常科研任务无需论文；论文复现使用同一主流程作验证。用户只确认软件无法取得且影响科学含义的条件，不抄写已存在的文献参数或操作后台。

## 开始门槛

1. 固定一个可从默认分支安装的版本；各依赖 PR 经授权独立审查、所需 CI 通过，并在支持平台完成实际分析和图像导出检查。
2. 使用本项目私有模型配置，核实当前有效模型 ID、密钥可用性、账本策略及显式连接自检。GET 与保存配置不得产生付费请求；失败和用量同一账本记录。不得借用其他项目凭据或静默回退到环境变量。
3. 固定任务版本、资源版本、HPC 连接、引擎和分析方法；备份并验证任务、账本和证据可恢复。集群七天硬限制、32 核/8 GiB 单作业、并发 1、完整记账和 B 最多两次继续有效；历史总额度与 Codex 固定储备比例不再阻塞。

## 单项任务协议

1. 保存原始自然语言和附件。自动提取材料、结构、条件、目标量、来源及冲突；关键缺项集中向用户说明。论文任务先核对完整题名/DOI、图/子图/表格及工况，选择目标，再冻结分析、评分和提交规则；不能把事后清单倒填为事前计划。
2. 复用已有文献工作台、Zotero、公开补充资料、资源目录及 HPC 软件。作者源码与对应势函数、参数和结构依赖齐全才进入 A 的准备；`bundle_complete` 只表示资料齐，不表示运行或科学通过。来源版本、许可和摘要必须可追。
3. 应用模型提出结构、势函数、输入脚本与分析方案；Adapter 检查元素与原子类型顺序、单位、边界、势函数适用性、LAMMPS 语法和资源。未知关键科学条件停下请求澄清，不编造默认值。冻结输入与工具身份后才可提交。
4. 所有目标物理计算仅经已授权、已记账的 HPC 服务。状态不明先查原请求，不能重发；正式评测最多两次，第二次只见自身日志和无答案反馈。监控跨浏览器关闭与服务重启保留作业身份、费用和失败历史。
5. 分别判断调度完成、输出有效、科学通过。原始输出按摘要回收，图表从真实任务和真实数据选择；显示单位、条件、来源和方法。交付处理后数据、多个图表、结构/轨迹（适用时）、报告、日志、原始下载和可追问分析；无证据不显示完成或虚构数值。
6. 后续正式 P–A–B 在 B 前冻结允许输入与隐藏资料，并用身份、挂载、工具和网络规则强制隔离。A 直接运行作者原流程；B 独立生成。第一周新上下文子 Agent 的独立生成记录保留，不能代替正式系统隔离检查。

## 工程与验收

代码经 Issue → 独立工作树/分支 → PR → CI → 授权 Review → 顺序合并。deepseek-harness 与控制端按当前交接文档划分资源库、模型连接、账本、执行和分析文件；不覆盖共享目录中的其他工作。新错误同轮记录证据、影响、原因或假设、修复和复验状态，保留每次费用。合成测试、真实模型、真实 HPC、跨平台安装、科学评价和空白页操作分别验收。

第二周完成须有一个全新任务从空白页经真实项目模型调用和真实 HPC 作业到证据完整的结果；再基于真实失败形成可审查改进 PR，并同输入、同预算复验。报告样本量、来源分组、覆盖、失败、人工介入和成本，不从单篇或单点外推 90% 泛化。未完成的门槛明确标未通过，不以页面截图或绿色单测代替。
