## 不变量

- 批次保留不可修改的初始预算及追加的显式批准修订。没有批准策略不能登记评测。
- 评测身份固定为批次、任务摘要、独立重复序号、角色、系统摘要；不接受显示名称重置额度。
  这些身份由受信注册端分配，不能允许 Agent 自行新建批次或重复序号绕过上限。
- SQLite `BEGIN IMMEDIATE` 同时占用提交额度、并发、最大核秒和存储。默认最多两次。
- 同幂等键只能绑定相同输入摘要及资源；重复调用返回已有请求，不重复执行调度 I/O。
- `dispatch_intent` 在网络调用前提交。进程崩溃或连接不明保留额度和预算，先按请求标识对账。
  它是保守提交计数，不能声称每个意图都已到达调度器；摘要单列接受作业、明确拒绝和不明状态。
- 审计写失败使事务回滚，调度调用不会发生。事件追加后不可通过普通 UPDATE/DELETE 改写。
- 取消请求不等于取消完成。已接受作业须等待调度器终态；未派发的取消不计作真实提交。
- 明确拒绝仍消耗提交机会；释放核时但保留可能已上传文件的存储占用。
- 已结束作业在获得最终核算证据前继续按最大核时记账。实际超支照实记录，阻止后续请求；
  派发前再次检查，防止已准备请求绕过其他作业刚暴露的超支。
- 所有终态仅指调度状态，不包含输出有效或科学成功。终态矛盾/重排队观察保留为事件，转入
  `reconcile_required` 并阻止新提交；自动重排队核算尚未实现。
- 数据库只允许仓库外私有文件，不覆盖其他应用的数据库，不允许直接软链接。

## 验证

运行 `python3 -m unittest discover -s tests -v`。新增覆盖：多进程最后一次额度、最后核时、
并发上限和重复派发；记账故障；接受后断线；worker 真正退出后的恢复；拒绝计数；取消；真实超支记录；终态矛盾；
重复最终核算与非本项目数据库保护。全部为合成输入，不触碰集群。

## 尚未完成的执行边界

本模块不是操作系统权限隔离，也不验证真实输入文件或调用 LAMMPS。后续生产适配器必须：

1. 校验全部文件、路径、脚本和固定 manifest，使用独立不可覆盖远程目录。
2. 复用已审计的 SSH/SFTP 边界并修复主机认证、命令引用和前置记账缺陷。
3. 给调度作业绑定请求标识，持久保存原始命令/回执与输出，处理迟到接受和对账。
4. 将核数、墙钟、内存落实到调度申请；以文件/文件系统机制落实存储限制。
5. 记录实际执行、子任务、重排队、完整核时及取消回执；当前暂不支持数组/自动重排队。
6. 用服务身份隔离评测注册、预算、参考资料和生成端；不能仅靠这份文档和数据库触发器。

在以上接口、冻结科学任务和授权审查到位前，不进行目标物理计算。
