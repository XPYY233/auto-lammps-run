# 文献条件导入

关联 Issue #11。此入口连接已有 Auto Research 证据导出和任务条件页面，不提取新论文、不调用模型、不执行作者代码。

## 当前支持

在任务中选择“从文献导入条件”，读取或粘贴一条 UTF-8 CSV，预览论文标识、页码、原文及结果上下文。仅允许从 `material`、`conditions`、`conditions_text` 取值；材料列只能填入材料字段，条件列只能填入明确的科学输入字段。每次明确选一列和一个字段，整个原始值原样导入，不从自由文本或嵌套 JSON 推断参数。单条文件最多 64 KiB，一份任务最多保留 32 个不同来源文件，沿用每字段 16 个候选上限。

操作者必须声明这次选择为任务输入，并对该证据条目选择 LAMMPS 直接结果、LAMMPS 后处理、其他方法或来源不明确，填写分类依据。分类初始为空，不从文章标题或包含 LAMMPS 字样自动推断。分类为其他/不明确仍可保存供研究核对，不构成合格复现参考；目前冻结依然只锁定审阅记录。

结果列、发现文本、图注和结果单位不自动成为输入。图注可用于核对来源，但不能取代条件列。结果字段及原文可能包含答案，全部保存在受信操作者的私人审阅区；**导出不是主 Agent 包**，不能交给正式评测生成端。

这不是语义级防泄漏：如果上游把结果误填入条件列，标签检查无法发现。仍须核对原文。自由文本、单位等价和跨条件科学检查尚未实现。整个条件列包含多项内容时，应先在上游形成粒度合适的条件证据，不把整段混合内容误当单一数值。

## 格式与来源

只读审计了 Auto Research 提交 `69b83f16ec746e825e0f6be5bae8cd83474414b5` 的 `src/auto_research/evidence/evidence_export.py`。其导出为带 BOM 的 CSV，包含一行证据和身份、出处、材料、条件、结果等列。本适配器独立编写，仅使用列名契约；没有复制受限源码或依赖其运行环境。该项目有限本机许可不授权一般改编再分发；论文、原文及数据的原有权利不变。

必需列为 `source_scope, source_id, entity_type, entity_uid, doi, article_title, source_locator, source_page`。允许保留其余有合法名称的列，最多 50 列；重复列、列数不等、多个数据行、无效编码或超大文件拒绝。文献需有 DOI 或标题，导入输入另需来源位置或页码以及原文/图注/上下文。格式匹配不认证文件真伪。

不获取 DOI 链接，不访问文件内路径，不执行公式、HTML、命令或附带指令，也不消除 CSV 为表格安全加的前导字符。页面通过纯文本节点显示来源。结果 `unit` 不会用于输入单位；条件自身的单位文本原样保留。

## 保存与可追溯性

预览无写入。确认导入时服务器重新解析同一 CSV，并核对预览摘要。原始 UTF-8 内容 SHA-256、完整原文、解析行、所取列、方法分类及依据与新条件在同一事务保存。客户端不能提交任意解析结果替换来源。

导入追加未确认的候选；不同值会清除已选值并撤销原确认。同一文件/列/目标字段重复导入拒绝，过期版本与已冻结任务拒绝；任何错误均不留下半份来源。修订事件和历史证据不覆盖。冻结导出包含来源快照并进入 `record_sha256`，仍明确未科学验证、未获执行授权。

`POST /api/literature/preview` 接收 `csv_text`；`POST /api/tasks/{id}/literature` 接收它与 `revision, source_sha256, column, field, evidence_role, method_class, classification_basis`。均受现有同源、Host、请求大小和严格字段约束。当前仅单人本机操作者可用，不代表已建立多人权限或盲测隔离。

## 验证范围

合成测试覆盖 BOM、多行原文、错误格式、结果与单位误用、无出处、摘要不符、重复导入、陈旧版本、候选上限回滚、冲突撤销、重开及冻结摘要。ASGI 请求验证预览不写入、条件导入与跨站拒绝。浏览器已用独立合成数据库实测粘贴 CSV、预览、明确映射、输入声明、导入冲突、刷新及来源展开；未将合成记录放入实际工作区。

尚未完成已安装旧工作台真实文章导出至本页面的端到端验收；文件选择路径、真实提取准确性与科学条件适用性也不能由上述合成测试证明。没有 HPC 作业或模型调用。
