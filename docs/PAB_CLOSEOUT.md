# Scoped P–A–B closeout

The operator result view can show a controller-retained user acceptance record,
original paper figures, computed A/B curves, scalar P/A/B differences and the
coverage of figures/tables. User acceptance has a stated date and scope; it does
not rewrite diagnostic science status, ledger identities, costs or attempt limits.
It does not imply whole-paper coverage, a pre-registered score or API automation.

A private `closeout/manifest.json` alongside an existing reference report binds its
exact digest and DOI. All evidence, figures and downloadable records have bounded
names, sizes and SHA-256 identities. The evidence record binds a completed,
accounted agent request from the same task. B's declared scalar output is read
through the existing raw-output receipt verifier and reanalyzed using the existing
scalar adapter; comparison differences are derived, not copied from UI metadata.
The retained analysis plan digest is checked without asserting it was frozen before
execution. Unit/window matching is required for the exposed metrics. The original
A report remains separate and unchanged.

This is a local controller publication for the first-week closeout, not a new
manual approval queue for runtime AI. There is no browser POST/publication endpoint
and no path from the closeout response to candidate generation or evaluation repair.
The existing post-result assistant continues to use its separately bounded context.
Real automatic target extraction, pre-execution selection/freezing, resource-bundle
onboarding and trajectory analysis remain unfinished work; showing a coverage list
does not implement those workflows.

The local preview uses a separate task/ledger snapshot and private reference-report
copy. Real paper images, output data, acceptance records and identities are excluded
from public Git history. Deployment remains local; redistribution/licensing review
is still required before public hosting.
