# Agent 候选方案与结构准备

Issue #23 将独立模型接口、结构工具、势函数适配和输入快照串成候选生成服务。
这是执行主流程的一段实际代码，当前没有正式运行授权或真实模型能力验证。网页入口与阶段历史见 [准备记录](CANDIDATE_HISTORY.md)。

## 当前路径

`generate_research_candidate` 读取普通研究任务的已冻结条件，只投影已选值，关联原条件记录摘要。
不把原始提示、未选条件、来源上下文或参考端资料发送给模型。当前此桥接入口仅接受用户输入或
已确认建议；文献/作者代码来源的任务仍等待独立输入发布和隔离核验。
后续合格测试任务须进入同一个 `generate_candidate_draft` 与执行流程。

服务向模型提供允许使用的势函数摘要、已记录的适用范围、任务条件、单位、几何工具范围和输出协议。
主 Agent 生成结构规格、势函数选择、独立编写的科学计算命令与分析方法说明。
存在缺项时返回具体问题，不能补造默认条件或缩小任务。此要求会写入提示；
当前尚无自动科学语义核验，不能只凭模型声称没有问题便认为条件已正确落实。

服务随后调用 ASE 准备几何、解析势函数资源、组装确定性初始化语句，把模型编写的工作流接在后面。
固定结构、模型、许可证、输入脚本、分析说明、原始方案及请求/结构/资源记录一并进入现有输入快照。
所有候选标记为 `candidate_prepared_review_required`，`execution_authorized` 始终为 false。
这里的状态标签不代替提交入口的权限控制；正式执行仍需已审查部署、科学检查和受信提交账本。

## 几何工具

可选依赖 ASE 3.29.0，仅调用 `bulk`、`Atoms`、重复晶胞、显式位点编辑和 LAMMPS data 写出；
没有计算器、能量/力/应力评价、弛豫或动力学。
支持沿 [100]/[010]/[001] 的常规立方 fcc、bcc、diamond、rocksalt、zincblende 晶胞。
晶格常数、重复数、边界、原子类型顺序及质量必须显式给出。
空位和替位使用编辑前的零基位点索引；不支持的取向、结构或任务须保留为缺项。
服务在分配结构前限制原子数，默认上限 100000；这不是 HPC 资源许可。
输出记录 ASE/NumPy 实际版本、组成、晶胞、规格及数据哈希。LAMMPS data 不保存边界类型，
服务将其明确写入初始化命令与记录。

Issue #51 增加内部规格 `crystal=explicit_cell`，支持明确晶胞与基元的非立方结构、合金及带真空层结构。
它是同一 Agent 准备接口的扩展，不要求研究者填写坐标表，也不为某篇论文生成专用工作流。
Agent 须从允许的条件或已核验资源取得这些信息；尚无自动结构资源检索，缺少依据时继续询问，不能编造晶胞。

该规格必须包含 `crystal, cell_angstrom, site_elements, scaled_positions, repeat, orientation,
boundary, vacancies, substitutions, type_elements, masses_amu`，不混入立方规格的 `elements/a_angstrom`。
`cell_angstrom` 为按行存放的三个向量，采用 `[[ax,0,0],[bx,by,0],[cx,cy,cz]]`，三个对角分量为正，
每个分量绝对值不超过 1000 Å。`orientation=provided_axes` 保留给定笛卡尔坐标系；不静默旋转晶胞，
避免几何坐标变了而后续加载方向或应力分量没有跟着转换。其他坐标表示目前要求澄清。
所用表示依据 [LAMMPS 三斜盒说明](https://docs.lammps.org/Howto_triclinic.html)。

`site_elements` 与 `scaled_positions` 逐项对应；分数坐标须在 `[0,1)` 内，不自动回卷、排序、对称化、
添加真空层或弛豫。完全重合的基元位点拒绝；这不代替最短距离及科学结构检查。
体积不大于 `1e-12 Å³` 或体积与三边长度乘积的比值不大于 `1e-10` 时，视为数值退化并拒绝。
重复前即检查原子上限。重复顺序为 x 外层、y 中层、z 内层、基元最内层；缺陷索引沿用编辑前的此顺序。
输出保留所有非零倾斜量，包括低于 ASE 默认倾斜判断阈值的小量，且关闭晶胞约化。
结构回执记录基元数、重复顺序与坐标系。作者 A 输入保持其自己的结构生成方法；本工具不能替代作者入口。

依据 [ASE 建模接口](https://docs.ase-lib.org/ase/build/build.html) 和
[LAMMPS data 接口](https://docs.ase-lib.org/_modules/ase/io/lammpsdata.html)。
没有复制 ASE 源码；使用独立安装的 LGPL-2.1-or-later 包，详见 LICENSE_INVENTORY.md。
ASE 已固定版本，其传递依赖尚未形成发行用完整锁定清单。

## 生成检查与历史边界

模型调用仍通过已有私人 `ModelCalls` 额度管理；同条件、资源和实现协议派生相同请求标识。
刷新或重启后重复请求拒绝再次发送；未知请求不能自动重试。网页可读取已完成候选与准备历史，
原始响应保存在私人调用记录中，快照可独立验证。
无可用资源或零额度时不请求模型。已有成功模型响应即使后续候选格式检查失败，也保留在调用记录中。

命令筛查拒绝外部执行、脚本包含、动态命令及控制流循环，检查声明的输出文件。
多个科学计算阶段可明确列出；尚不能自动识别其是否构成隐藏试错或是否覆盖科学目标。
允许的变量表达式与命令参数也尚未得到完整语义分析，因此这不是脚本安全验证器或科学验证器。
所有模型脚本仍是不可信数据，绝不在本机执行。

现有启动器仅挂载声明的平面输出文件，故候选写入 `/output/<文件名>`；标准日志由启动器提供。
生成器版本 2 增加可冻结的数值表分析计划，支持列单位、预定区间、统计及线性拟合；版本 3 增加显式晶胞协议，见
[分析范围](ANALYSIS.md)。旧的自由文字说明仍标为未实现；结构分析与 OVITO 尚未接通。
冻结资源上限不表示已经为提交账本预留预算；候选生成不消耗 HPC 提交次数。

## 已验证与剩余

实际 ASE 检查覆盖原子数、晶胞、显式质量、位点编辑、类型顺序及文件往返；测试禁止调用能量、力和应力方法。
新增检查覆盖四方与三斜合成晶胞、微小倾斜量、重复位点编辑、非法/退化结构及分配前上限。
显式结构和 MEAM 资源已经通过同一候选后台、历史与文件读取的合成验证，未运行物理引擎。
合成模型响应通过真实调用计数、适配器和快照路径，覆盖失败响应保留、重启防重发、零额度和文献输入阻断。
这些证据证明软件连接与几何操作，不证明 DeepSeek 能正确设计计算。

仍需真实模型配置和批准额度、科学条件落实检查、输入发布/隔离、完整任务的工具覆盖、
真实 HPC 提交回收、一次修复、完整任务的分析和 P-A-B 验收。不能把生成了候选文件当作第一周目标完成。
