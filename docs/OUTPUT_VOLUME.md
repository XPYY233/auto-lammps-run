# 固定容量输出卷

Issue #61 为完整轨迹增加可选的 ext2/FUSE 输出后端。原启动器把额度平均分给每个文件，
一个大轨迹可能先达到文件上限，而其他文件的额度一直闲置。新后端让所有声明输出共享
固定容量的文件系统；不改变计算步数、原子数、输出列或采样间隔。

## 分配和权限

管理员在受许可摘要约束的 runtime.json 中增加 `output_volume`：

```json
{
  "kind": "ext2-fuse",
  "max_image_bytes": 16777216,
  "mkfs_path": "/trusted/storage/mkfs-pinned",
  "mkfs_sha256": "<64 hex characters>",
  "fuse2fs_path": "/trusted/storage/fuse2fs",
  "fuse2fs_sha256": "<64 hex characters>",
  "fusermount_path": "/usr/bin/fusermount3",
  "fusermount_sha256": "<64 hex characters>",
  "helper_directory": "/trusted/storage/helpers"
}
```

示例仅说明字段，不构成部署或计算授权。容量由冻结资源减去输入、262144 字节控制预留和
两个各 65536 字节调度流预留后计算，向下对齐 4096 字节，再取管理员容量上限；至少 8 MiB。
预留整个镜像，包括文件系统元数据，不把稀疏文件的暂时占用当作释放额度。

mkfs、fuse2fs 和卸载工具须固定真实文件摘要，不能在可提交目录内。
工具核验保留不接受硬链接的规则：系统 mkfs 有多个硬链接时，部署端需在私人受信目录保存
经摘要核验的独立副本。不能通过复制卸载工具丢失系统授予的挂载权限。
`helper_directory` 须仅本人可访问，其中 `fusermount` 链接精确指向已固定的卸载工具。
已有系统默认 fusermount 如与声明不同则拒绝；不根据输入临时选择其他工具。
这一处理适配已发现的 libfuse 2 与系统 fusermount3 名称差异。

启动器独占创建 `output-volume.ext2`，格式化 ext2，不启用日志；FUSE 在前台运行。
守护进程的文件大小硬上限等于镜像容量，内存地址空间上限 512 MiB；其总实际内存和 CPU
还必须受同一作业 cgroup 管理。核对实际挂载类型、镜像路径、所有者、模式和文件系统容量，
不以启动返回成功代替挂载检查。新后端的路径暂不支持空白或反斜线。

目标程序仍只获得原先逐个声明的可写文件，不能写镜像、挂载目录或调用工具。
单个输出可以使用共享剩余空间；满卷由文件系统拒绝继续分配。没有把轮询磁盘使用量当作硬限制。
这约束的是输出文件系统及其 backing image，不是整个项目所有目录的物理配额。

## 持久化与回收

执行意图保存输出后端和容量；同一请求仍不能再次执行。进程结束后先卸载，核对守护进程
正常退出与镜像身份/大小，再记录执行完成。卸载失败、遗留挂载和版本不符均阻断，不自动
删除镜像、不重新运行物理计算。

回收要求原执行配置摘要、输入资源和记录容量相符，只读重新挂载原镜像，沿用已有逐文件
摘要和有界传输协议。镜像从未提供给 Agent 作为输入或可写文件；该名字在本地与远端上传
都保留。只读回收结束核对镜像没有变化，卸载并保留镜像。下载副本仍按原账本额外计费。

## 验证与未完成

在指定登录入口用 8 MiB 合成磁盘验证了非均匀输出、写满返回 ENOSPC、镜像不增长、
卸载后只读重开、SHA256 一致及只读写入返回 EROFS。没有目标材料或 LAMMPS 计算。
首次只读尝试使用了安装版本不支持的选项，失败保留；改用该版本支持的只读选项后通过。

实际后端也通过同一 8 MiB 存储检查。过程中发现并修正共享父目录不允许列目录的问题：
Linux 使用 O_PATH 穿越父目录，末级仍保留可用于 fsync 的描述符。还发现 fuse2fs 的 ro 选项
不足以使内核挂载只读；回收同时传入 -r 与 ro，并核验真实挂载模式。失败回执均保留。
同一执行/回收链路另有离线测试，结果记录在 PROGRESS.md。计算节点 FUSE 可用性、
完整 sandbox 与 MPI 同时运行、满卷后的科学输出检查仍需验收。
调度流/控制文件的外部硬限制、GPFS 实际块开销、工具和运行树以及全部历史副本的全局存储
核算仍未完成。用户已允许扩大项目存储，首轮实施上限选为 16 GiB；这不证明整篇论文全部条件均能在该额度内完成，
也不代表新预算或本后端已经部署。其他资源与 API 额度保持不变。
