# 参考端自动证据草稿

关联 Issue #45。`reference_generation.generate_reference_draft` 将文献工作台已有导出
交给独立运行模型，整理未确认输入条件、论文报告结果和逐项方法依据。它是内部参考端
服务，尚未接网页按钮、自动文献获取或正式评测；不是开发者手动提取成果的包装。

## 来源与输出

接受同一文献的 1 至 8 条现有 CSV 导出，复用已核对的格式适配器。每条须有文献标识、
页码/位置及原文、图注或上下文。原始导出及摘要在发出请求前保存到不可覆盖的参考意图
记录；模型只收到这三类证据文本及出处，不能获得终端、网络下载或提交工具。

只存在于导出数值栏、没有原文支持的数字化结果不自动当作原文。图像/曲线数字化仍需
单独的验证接口；当前没有通过重写原文来制造引用。多文献混入、重复来源、超限文本和
缺少出处在发出请求前拒绝；模型请求另外受现有配置的字节、token 和调用次数上限约束。

模型返回三组条目：

- 输入条件：复用现有 `field/value/unit/source_id/quote` 校验，加入未确认候选。
- 报告结果：保留物理量、原始值、单位、连续引用、来源摘要；另附该结果自己的方法分类
  及原文依据。方法不明确时保留 `unclear`，不从整篇包含 LAMMPS 推断每个结果的来源。
- 缺项：原文不足、条件冲突或结果定义不明时保留具体问题，不猜参数或判据。

输入和结果在同一事务导入。任何错误均不导入半份条件；已发生的模型调用与原始结构化
响应仍保存在模型账本。冲突值保留，新增不同条件会撤销旧确认；结果相互冲突也不取平均
或静默选一个。结果尚未具备独立科学核验、图表定位校正或评分资格。

引用、值和单位确实出现在文字中，只证明文本一致，不证明科学含义、输入/答案分类或
方法判断正确。因此条目保持 `model_proposed_not_verified`、`eligible_for_scoring=false`，
批次保持 `reference_qualified=false`，不能据此建立合格 P/A 或发布 B 输入。

## 记账与恢复

相同任务、导出、请求内容和适配版本产生确定的请求标识。成功导入后重复调用直接读取
原批次；如果模型已返回但任务导入中断，重开服务可用账本内原响应恢复，不再次发送。
任务在请求期间被编辑会拒绝陈旧导入，刷新后可将同一来源响应作为未确认草稿导入，
保留新的人工修改与冲突。模型来源文本不含任务当前候选，因此这种恢复不更改模型依据。

并发遇到尚无完成回执的意图，以及超时、拒绝或无法核实的请求，都要求核对，不能自动
重试。来源持久化失败阻止请求；额度为零仍不发送。受信服务不得以新任务、伪造来源或
新模型账本绕过既有额度。用户的 API 时点与第一周验收口径尚待明确；本功能默认未启用。

## 参考端与主 Agent 的边界

`reference_batches` 只进入参考端任务记录及冻结参考准备包。现有执行任务草稿仍仅复制
已选输入字段，不携带结果、原文、导出或方法依据；普通科研任务拒绝该参考接口。这个
字段边界不是语义防泄漏或操作系统隔离，正式发布仍需验证输入含义与部署访问边界。

开发者只编写和调试代码。实际来源理解、条件/结果提取及后续参考流程准备由独立 API
和应用工具完成；当前测试中的合成响应不证明真实模型能力。进入 B 前仍须单独报告策略
并获得用户确认。本模块不配置 API、不发起作者计算、不生成 A/B、不变更任何提交预算。

## 验证

离线检查贯通原创合成导出、真实模型记账接口的替代传输、引用校验、事务保存和冻结
导出，包含导入中断恢复、并发、陈旧版本、未知请求、零预算、错误引用、冲突及答案字段
不进入执行草稿。尚无真实 API、真实文献自动提取或 HPC 验收；不改变第一周未完成状态。
