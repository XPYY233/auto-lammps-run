# 科学评测规范（未冻结）

P 为论文结果，A 为作者代码参考运行，B 为主 Agent 独立生成结果。先核验 A-P，不符合的参考不得进入合格分母。所有开发失败、人工修改、排除原因和成本保留。当前查看过的论文均为开发候选，不得标为本系统未见盲测。

用户要求：进入 B 前，先报告提供给主 Agent 的任务与允许资源、隐藏资料边界、提交计数、
一次修复可见反馈及评分策略；获得用户确认后才启动 B。A 的准备、开发授权或已有预算
不替代这项确认。此要求针对文献测试阶段，不把论文或参考 A 变成普通研究入口的前置条件。

A 必须直接运行固定版本的作者源码及其原有入口和配置，并保留调用记录。不得由开发者或参考 Agent 独立重写模拟输入、手工重建模板流程或擅自补定缺失科学参数后仍称为 A。必要的依赖与路径兼容改动须逐项留痕并验证其影响，不能替代缺失的原始科学流程。B 才从允许输入独立编写计算流程。

正式任务每次独立评测最多两次提交。真实调度请求、接受作业及子任务、执行和重排队分别记录；参数错误拒绝也记失败。网络结果不明先查重，禁止盲目重试或改名重置额度。阶段内最小化、平衡、生产可以属于预先声明的一次作业；作业内不得自行试错重启。多条件/多作业任务的拆分和计数提前冻结。参考、开发、分析另记账并计入总成本。

第二次只使用自身日志和不含答案的反馈。评分器不泄露 P、A、差值或目标曲线。基础设施故障分类报告，同时报告包含其影响的整体结果，不事后豁免失败。

成功须同时满足：条件一致、真实计算完成、必须输出齐全、预定科学容差通过、提交和资源未超限、无人修改 Agent 方案、全链可追溯。静态通过和调度完成均不是科学成功。

候选标量规则：s > 0；e(X,Y)=abs(X-Y)/s；a=e(P,A)，b=e(A,B)，c=e(P,B)。a 称参考复现偏差。先限制 a 的入选上限，再要求 b <= max(a,u)、c <= a+u；如有科学上限还须 c <= tau。s、u、tau 和参考上限在查看 B 前确认。近零量使用事先约定绝对尺度。它是待确认的设计，不是通用统计定律。曲线和随机任务单独定义判据。

必须量逐项通过，不能用平均掩盖失败。区分 Agent 波动与固定脚本随机波动；不把时间相关帧作独立重复。按论文、仓库家族和方法分组，不把 fork 或同曲线多温度当独立来源。报告 R1、R2、样本量、置信区间、误差、覆盖率、人工干预和总成本。R2 >= 90% 是阶段目标，不是承诺。

基线与新系统尽量使用同模型、输入、工具、资源和预算。冻结测试后不能更新系统、改变阈值或删除困难任务。用测试失败改进之后，该任务不再是新版本未见测试。改进须为新分支与审查 PR；禁止自行修改答案、评分额度、权限、预算和历史。

测试层级分开：离线单元、模拟外部集成、真实模型、真实 HPC、科学复现。必测：缺参、元素/单位不符、缺文件、超预算、重复/不明提交、重启、截断和旧输出、路径攻击、未授权命令、隐藏资料访问、超额修复和取消。CI 只测前两层。
