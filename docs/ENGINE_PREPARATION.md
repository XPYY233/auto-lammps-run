# 计算环境准备

参考端从已收集的势函数调用声明提取 MEAM / `meam` 要求，由受信配置指定
LAMMPS 发布版本、官方源码 commit、核心数和存储上限。版本日期、Update 后缀、
已编译包、pair style 和 MPI 能力分别核对；缺项不会自动选择另一个版本。
目前支持 MEAM，尚不覆盖任意势函数包。

管理员入口：

```sh
python3 -m auto_lammps.engine_preparation \
  --database /private/tasks.sqlite --paper-id PAPER_ID \
  --audit-directory /private/engine-audit --policy /private/engine-policy.json
```

配置必须包含 `release`、`commit`、`cores`、`storage_bytes`、`host_alias`、
`remote_directory`、`operation_id`。后两者分别是超算私有目录的绝对路径和
32 位十六进制准备标识。路径、集群身份和真实回执不得加入公开仓库。
这是管理员配置，不要求科研用户填写。

控制端通过配置的 SSH 别名发送本项目的固定工作程序和结构化要求。只在 Linux
SSH 会话中执行真实源码下载；本机不下载 LAMMPS 源码，也不解包或编译。
工作程序内容的 SHA-256、请求、连接观察和结果回执留存在审计目录。
真实源码、压缩包、清单和工作程序副本保存在超算。

只访问官方 codeload 地址中的固定 40 位 commit，验证 TLS，不跟随跳转。
下载最多 256 MiB，选择性解包最多 1 GiB、50000 个成员，仅保留 src、cmake、lib、
LICENSE 和 README。拒绝越界路径、硬链接、链接链和特殊文件；归档内指向已选普通文件的符号链接
按目标字节保存为普通文件，并在清单中记录转换关系。保留失败下载，不执行源码或
安装钩子。保留归档与文件 SHA-256；源码内的版本声明必须匹配配置。
这些检查不证明源码没有漏洞，也不证明环境能够运行作者任务。

同一 `operation_id` 绑定同一主机、目录、要求、源码版本、预算和工作程序版本。
远端先独占记录请求，再准备源码。同一标识再次访问只读取已有结果；未有结果时
返回“待核实”，不会重启准备。连接超时或回执异常也显示“待核实”，保留运输记录。
管理员核实进程和文件后才可决定是否开启新的准备标识；不得以观察超时为依据重试。
同一标识不能用于升级工作程序。失败记录和旧源码不自动清除。

页面显示源码准备状态，文献历史保留待核实、失败和准备完成记录。
源码检索管理员入口可用 `--engine-policy` 在势函数获取后串联本步骤；自动论文导入
仍未连接该入口。原有作者源码和势函数获取还使用控制端存储，迁移与引用更新待完成。

`cmake_plan` 仅生成有界的 MEAM/MPI 构建方案，不执行编译。构建、环境验证、
物理计算及正式部署仍须使用已审阅版本和记账的超算资源。源码准备不占用模拟提交
次数，也不产生 A/B 结果。单次源码获取的字节边界不能替代全项目存储核算；总存储
预算及不同副本仍需部署层统一落实。
