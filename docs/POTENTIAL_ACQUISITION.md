# 自动准备 MEAM 资源

Issue #63 将论文源码检索与势函数获取串联：找到唯一一项题目和 DOI 均匹配的仓库后，
参考端自动读取固定提交的目录和输入声明，取得 MEAM 库及参数文件，校验 Git blob 与 SHA256，
记录元素索引、原子类型顺序、单位、所需 MEAM 包和 pair_style。网页显示获取结果及历史。
原件保存在私人审计目录，不写入公开代码，不执行下载的脚本。

同一源码检索入口现在自动调用资源准备。对已经有源码检索结果的论文，可单独恢复此步骤：

```sh
python3 -m auto_lammps.potential_acquisition \
  --database "$HOME/.local/share/auto-lammps-private/workbench/tasks.sqlite" \
  --paper-id PAPER_ID \
  --audit-directory "$HOME/.local/share/auto-lammps-private/potential-acquisition"
```

这是受信参考端入口，不是主 Agent 的下载或源码阅读工具。主 Agent 仍只从已有势函数目录
读取获准资源；本步骤没有把作者输入、答案或运行权限给主 Agent。参考材料和产品资源的
正式放行与隔离仍需完成。

## 当前支持范围

- 固定 GitHub 提交及其目录树；最多 2000 个目录项、8 个不超过 100 KB 的候选输入，最多
  30 次请求，每次传输响应最多 2 MB，单个模型文件不超过 1 MB。请求先记录意图，原始响应和
  失败随后保留；目录被截断时拒绝声称完整。每次调用产生独立记录，不覆盖失败。
- 只解析明确的 `units metal`、单独 `pair_style meam` 与一条字面量 `pair_coeff`。
  路径缺失、根目录与输入目录存在歧义、动态引用、跳转、包含其他脚本、混合势和重置流程
  均保留待处理项，不猜测或执行脚本以求值。下载来源不跟随符号链接或子模块。
- 原件逐字节保留；库元素索引与原子类型分别记录。相同文件被多个入口使用时只下载一次，
  各入口的声明分别保留。发现声明不代表该脚本曾执行或已经通过科学验证。
- 最多保存两份名称符合约定的许可文本。没有文本时明确记录未声明；找到文本也不自动证明
  对所有势函数适用，更不自动授予再分发权。资源获取不会直接加入可用目录或签发执行许可。

## 文件语义和兼容性

MEAM 静态检查增加 v2：保留参数文件按顺序重复赋值的原始字节，记录前值、后值及行号；
零原子序号记录为提示而非一概格式拒绝。提示不代表参数科学正确，也不自动修正可疑数值。
其他格式、元素映射、有限数值和受支持命令检查保持。原 v1 目录记录按旧版本规则重新校验，
不重写已有内容标识；新导入使用 v2。绑定回执和候选资源摘要保留参数提示，模型需在说明中报告。
检查版本进入兼容性身份，避免已排队请求悄悄沿用变化后的策略。

依据是对应作者日期的官方实现：
[MEAM 文件读取](https://github.com/lammps/lammps/blob/stable_2Aug2023/src/MEAM/pair_meam.cpp)
逐行把设置传给
[参数赋值](https://github.com/lammps/lammps/blob/stable_2Aug2023/src/MEAM/meam_setup_param.cpp)。
未复制这些实现；没有用一次真实或隐藏模拟来判定解析规则。

自动获取将 MEAM 包和样式要求写入报告，**尚未自动安装或验证计算引擎**。已有资源适配器
的包清单仍是部署声明。引擎选择/构建、计算节点能力验收、自然语言任务的通用势函数检索、
NIST/OpenKIM 来源连接以及获准资源自动入库，仍属于未完成的产品链路。
