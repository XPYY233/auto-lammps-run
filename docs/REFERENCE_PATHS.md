# 作者参考输入的路径适配

`reference_paths.adapt_reference_scripts` 是参考端的纯文本适配器，不是主 Agent 工具。
输入为已经生成的脚本字节及逐文件 SHA-256、入口、输出路径映射和初始输入文件名。
它不导入作者 Python 模块，不填写科学条件，不启动 LAMMPS、模型或调度器。
第一周由 Codex 负责参考流程准备与真实 P-A-B 验证，第二周再接入独立 API。静态转换不等于真实运行，也不计入独立 API 自动化验收；每次 Codex 参与与工具执行分别留痕。

已有运行器以只读方式挂载 `/work`，仅把声明的平面文件挂载到可写 `/output`。
作者脚本若在当前目录写入结果或中间状态，原路径不适合这一布局。适配器按以下方式准备：

- 按原顺序展开明确列出的字面 `include`，包含文件可以重复使用；循环和动态名称拒绝。
- 将 `write_data`、`write_restart` 和 `print file/append` 的字面路径转到声明的输出文件。
- 状态首次写入后的 `read_data/read_restart` 指向同一输出文件。首次写入前的读取必须是
  声明的初始输入，仍从 `/work` 读取；不会拿一个空的预创建输出充当初始结构。
- 接受 Windows CRLF 行尾，转换为 LF 并逐行记录；保留原始字节、原始摘要和末行补换行记录。
- 支持明确列出的逐原子 compute、atom 变量、deform/ave/atom，以及末尾只有一个 `file`
  选项的 `fix ave/time`。统计区间、值表达式和全部物理命令保留，不补默认值。
- 支持固定间隔的原生 `atom`/`custom` 文本轨迹，将文件名定位到声明输出。
  通配符输出默认拒绝。参考控制端明确指定 `combine_dump_frames=True` 后，可把一个 `*`
  的逐帧文件名映射到单个多帧文本轨迹，另记 `dump_layout` 改动。
  此模式仅支持一个 run 或 minimize，禁止活动期间 clear/reset_timestep、重新打开同一模式名，
  不支持 dump_modify、并行 `%` 文件名、动态间隔、压缩或二进制输出。不会猜测收敛步编号。
- 其余支持的命令和注释保持字节不变。末行缺少换行时补一个并记录，防止展开后命令黏连。
- 返回原件、展开脚本及回执：输入/输出摘要、每次包含、每处路径变更和输出行的原始位置。
  原件与回执由参考端私有保留，脚本及实际输入资产再通过已有 `manifest.freeze` 冻结。
  `input_files` 只是声明，不核验结构内容；冻结步骤仍须包含并校验实际资产。

当前只支持明确列出的命令子集。几何/变量条件分支可以原样保留；分支内读写、执行或包含、
循环跳转、变量文件名、三重引号、文件命令续行、额外文件选项和未支持的输出方式都拒绝。
势函数兼容性及其读入文件由独立资源绑定检查负责；本模块不证明完整输入语义或文件访问安全。
行为参照 LAMMPS 的 [include](https://docs.lammps.org/include.html) 与
[输入解析规则](https://docs.lammps.org/Commands_parse.html)，没有复制其实现。
轨迹文件布局与统计文件选项另参照作者使用版本的
[dump 文档](https://github.com/lammps/lammps/blob/stable_2Aug2023/doc/src/dump.rst) 和
[fix ave/time 文档](https://github.com/lammps/lammps/blob/stable_2Aug2023/doc/src/fix_ave_time.rst)。
多帧映射改变文件布局，原始分析程序若依赖逐帧文件名，需要另外适配并记录；不能宣称输出字节
不变或已证明科学等价。轨迹列、采样间隔、run/minimize 参数均不改变。

## 接入边界

返回的回执始终保留 `scientific_equivalence=not_verified`、
`author_invocation_verified=false` 和 `execution_authorized=false`。
路径适配不会自动建立合格 A，也不授予参考端执行权限。还需要完整任务、条件来源、输入
版本、容差、依赖、隔离与资源审核，以及原有参考角色账本和签名许可。科学默认值不能因
模板可生成而被视为论文实际参数；晶格优化和弹性等不同阶段的条件分别保留。

首个私人作者模板完成了静态适配：弹性流程原有阶段及中间状态写读数量保持；独立晶格
模板另存。未批准条件保留为缺项，未生成可执行授权。旧势格式转换的变化另有记录，不能
和路径变更合并声称数值等价。作者源码、目标值及真实核验资料均未进入公开 Git 或 Agent。

用户新增要求：**启动 B 前，必须报告输入与允许资源、隐藏资料边界、次数计算、修复反馈
和评分策略，并获得用户确认。** 继续准备 A 或通过离线检查均不满足这项确认。

## 已验证范围

Issue #55：新增原创新合成拉伸文本，验证 CRLF、逐原子统计、轨迹布局显式选择、跨文件来源、
路径与格式拒绝及已有输入冻结接口。353 项本地检查中 352 项通过，1 项 Linux 专用检查跳过。
实际选定作者脚本的私人静态核对表明：原件摘要未变，适配稿差异完全对应路径、行尾及记录中的
轨迹文件布局，未改变科学命令。首次辅助比较漏计了已记录的末行补换行，修正比较后通过，
失败保留。尚未执行 A，也没有基于这项转换证明科学等价。

当前运行器仍为各输出平均分配单文件上限；已选任务的完整拉伸轨迹即使按每个数值仅一字节的
保守下界，也超出该分配。需要修正存储分配/执行支持，不能删列、降采样或截短运行来适配限制。
总存储（含运行树与下载副本）、MPI、真实部署与审查仍未验收。

原创合成文本检查覆盖状态先读/后读、重复包含与递归拒绝、来源摘要变化、未声明文件、
条件分支限制、引号/注释、原行对应和已有冻结接口。没有在本地或 CI 执行物理引擎。
真正数值等价、参考运行、科学评分和第一周完整验收仍未完成。

此前手工组合晶格与弹性模板、补定调用参数的私人草稿已撤回，不能作为 A。用户明确 A 必须直接运行作者源码及原有运行配置，B 才独立编写输入。路径适配工具只可用于记录必要的执行环境改动，不能替代作者程序入口、补造缺失的科学调用或证明作者结果可复现。该草稿从未执行，原记录保留并标明撤回。
