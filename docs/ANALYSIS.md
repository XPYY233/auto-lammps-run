# 冻结计划的数值分析

Issue #35 把候选方案中的分析说明连接到 `AnalysisService`。普通研究和参考运行使用同一
适配器；参考结果仍保留在各自的受控身份下，不向被测 Agent 提供答案。此阶段支持基础
数值表分析，尚无结构识别、OVITO、置信区间或 P-A-B 评分。已保存报告可接入
[任务结果页](RESULTS_VIEW.md)，仍待真实计算验收。

## 从方案到报告

生成器版本 2 提示模型提供 `analysis.plan`，与输入一起冻结并纳入 `analysis_sha256`。
算法源码及 Python 版本也由服务写入冻结分析文件，执行后改变实现会被拒绝。
方法、列、单位和区间在计算前确定；不执行模型给出的 Python，也不看结果后自动挑选拟合
区间。旧的只有自由文字的候选可读取，但保持 `not_implemented`，不能假装已经分析。

最小结构示意，数值均为合成示例：

```json
{
  "tables": [{
    "file": "curve.dat",
    "columns": [{"name": "strain", "unit": "1"}, {"name": "stress", "unit": "GPa"}]
  }],
  "operations": [{
    "id": "curve_slope", "method": "linear_fit", "file": "curve.dat",
    "x": "strain", "y": "stress", "window": [0, 0.01]
  }]
}
```

每张表的前两条非空行必须是 `# columns: strain stress` 和 `# units: 1 GPa` 这样的精确
标签，随后只能是相应列数的有限数值。可由 LAMMPS 的
[print](https://docs.lammps.org/print.html) 或
[fix ave/time 的 scalar 输出与 title1/title2](https://docs.lammps.org/fix_ave_time.html) 写出。
这不是任意 LAMMPS 日志/轨迹解析器；vector 块输出和结构文件不能冒充这种数值表。

`summary` 返回区间内均值、样本标准差、最小值和最大值；单行时标准差为空。
`last` 返回区间内按原始文件顺序的最后一行，不排序或假定它已经平衡。
`linear_fit` 做带截距的普通最小二乘拟合，至少三行且 x 有变化，返回斜率、截距、残差
均方根及 R²；常数 y 的 R² 为空。拟合质量不是科学通过条件，标准差也不等于独立重复
实验的误差。时间相关性、有效样本量与独立重复的不确定度尚未估计。

单位须显式提供并与文件标签相同，不自动换算。LAMMPS 的
[单位约定](https://docs.lammps.org/units.html) 仍须在计算方案中核实；例如声明和表头都写
GPa 并不能证明脚本已经正确处理原生压力单位及应力符号。报告明确保留这一验证缺口。

## 调用与追溯

受信后台调用 `AnalysisService(collector, report_directory).run(request_id, snapshot)`。
collector 复用 [结果回收](OUTPUTS.md)，不新增计算提交。服务检查当前账本、完整且零退出
的执行记录、必须输出、快照和分析摘要，再核对输入文件字节。不同任务/输入、缺文件、
失败或未完成的计算、无可执行计划、NaN/Inf、错误单位及退化拟合均不能产生性质报告。

报告保存原始文件摘要、列单位、精确选中行号区间、样本数、分析窗口、输入/分析/回收
记录身份、算法源码和 Python 版本。`analyzed` 表示计划中的数值操作完成，科学状态仍为
`not_evaluated`；没有自动把斜率命名为某种材料性质，也没有读取参考答案。

每个报告先在批次账本预留 64 KiB；另一个输出目录的副本另计费。同一数据、算法/解释器
和存储位置复用同一分析身份；重复读取校验回执与原数据。报告和失败原因不可替换，写入
失败不能标为已保存。若进程留下损坏的半写报告，服务拒绝覆盖，需要受信恢复处理；本阶段
尚无自动清理/修复该文件的入口。物理存储配额和持续 worker 部署仍未验收。

计划最多 16 张表、32 项操作；所有表合计最多 8 MiB、500000 个单元格，单表最多 100000 行。
报告最多 64 KiB；过大的数据或来源行号碎片会明确拒绝，不能静默截断、抽样或减少科学任务。

验证使用手算可核对的合成直线、统计样本和真实本地子进程回收链路，没有真实模型调用、
目标模拟或科学性质复现。首轮集成测试因试图覆盖只读合成 manifest 失败，已修正测试准备；
没有修改真实冻结输入。

## 原生 LAMMPS 标量表适配（Issue #84）

`scalar_analysis.analyze_scalar(data, table, operations)` 直接读取原始字节，复用上面的
统计/拟合函数；不改已有 `numeric_tables_v1` 代码和冻结身份，也不为已派发任务替换计划。
格式依据 [LAMMPS fix ave/time](https://docs.lammps.org/fix_ave_time.html)：scalar 输出每步
一行，vector 输出为数组块。本适配器只处理显式声明的 scalar 文件，不自动猜格式。

表声明包含 `file`、`format=lammps_ave_time_scalar`、两条精确 `headers`、`columns`
（每列 `name/unit/source`）与 `steps`（`first/last/stride`）。首列必须对应 TimeStep，
单位为 step；第二行标题的顺序必须与 source 一致。固定首尾与步距用于识别整行丢失、
重复、倒退和中途重启，不能只检查最后一行是否换行。操作仍显式指定列和包含端点的窗口。

此原生格式没有单位标题，报告明确标记单位仅来自声明；不推断压力符号、应变、体积或
换算。保留原始文件 SHA-256、完整列映射、步数约束、选中源行、解析及算术版本。
整数步数不先转换浮点，避免大步数精度损失。截断、NaN/Inf、列不符、非 ASCII、额外
标题/注释和 vector 块均拒绝，数据上限沿用数值分析限制，不静默抽样。

这是解析和数值操作接口；报告显式写 `execution_status=not_checked`、
`plan_status=caller_supplied`、`scientific_status=not_evaluated`。调用方仍须验证输出回执、
任务身份和预先冻结的计划。不得将离线函数返回 analyzed 当作调度核算、正式评分或完整
自动跟进已经接通。旧计划继续使用原版本；当前真实 B 不因本次开发更改输入或评分窗口。


## 原生输出进入自动跟进（Issue #89）

生成器版本 4 可声明原生 scalar 表，也可在同一计划混合带单位表头的表。列、源标签、
单位、首末步/步距、操作和窗口均先验证后冻结；解析及算术实现身份进入候选请求身份。
服务选择 `numeric_tables_v2`，模型不能指定执行器或在结果出来后更改计划。

`analysis_v2.VersionedAnalysisService` 沿同一个 OutputCollector 与账本读取核验后的回收
文件，核对冻结规格、正常执行回执、完整输出清单及逐文件摘要，复用既有统计和拟合。
报告保留精确来源行、原始摘要、列映射、步距以及逐项单位来源。缺采样、非零退出、
解析版本变化或文件篡改保留失败，不输出部分科学性质、不修改或重新提交模拟。

worker 的自动跟进入口使用该版本化服务，跟进配置也固定服务实现身份。相同报告重复
读取和服务重建不增加计算提交或重复下载；写入失败可沿原分析预留恢复。已有带单位
表头的 v1 计划交回未修改的 analysis.py，保留原分析身份。旧跟进任务的配置身份不能
静默替换，部署升级应在新任务生效；当前真实 B 仍使用原监控与已固定输入。

结果页按报告显示单位来源：原生 scalar 无单位标题，不能声称已从表头验证单位。
该流程只处理当前支持的数值操作；结构/轨迹、OVITO、科学评分和真实模型验收仍未完成。
验证使用合成模型响应与调度状态，通过真实快照、输出传输、账本、报告和结果读取接口；
不是新增 HPC 计算或真实 API 自动化验收。
