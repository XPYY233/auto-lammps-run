# DeepSeek 条件整理

关联 Issue #19。产品的正常入口为自然语言科研需求，不要求论文。参考测试可使用同一条件整理服务处理明确提供的文献片段；主 Agent 的生成执行尚未贯通。

## 已实现

`DeepSeekClient` 使用官方 HTTPS Chat Completions 的非流式 JSON 输出，指定模型、输出 token 上限、输入字节上限和连接读写超时；关闭思考模式，不提供工具执行。固定官方主机，不跟随重定向、不自动重试。接口依据：[Chat Completions](https://api-docs.deepseek.com/api/create-chat-completion/)、[JSON 输出](https://api-docs.deepseek.com/guides/json_mode/)。

调用前在私人 SQLite 账本原子登记请求 ID 与内容摘要。默认额度为 0；重复 ID、额度耗尽均不读取密钥或发出请求。缺少回执、网络状态不明、被拒和未发出的登记都不释放额度。策略固定，重启不能重置计数。当前上限是请求次数及每请求输入/输出限制，不宣称已经实现按货币计价的账单上限。

记录请求摘要、时间、返回状态、响应摘要、提供方报告的 token 用量和错误类别。缺失用量保留为未知。成功的结构化回答也保存在私人账本中，后续条件校验失败或并发修改导致导入失败时仍可复查。上游错误正文和异常原文不输出，防止其中包含请求或凭据。异常正文仅有摘要，不声称已经保存其全文。

条件输出必须引用提供过的来源和连续原文，值及单位必须出现在引用中。错误引用、未知字段、额外授权字段会使整个导入失败。正确引用仅证明文字位置，不证明科学含义或输入/答案分类；所有新条件仍待确认。保留来源、回答、模型回执、缺项问题和冲突，不自动覆盖条件。相同证据再次出现不会重复添加，也不撤销已有确认。

## 网页与数据范围

网页正常研究入口只发送已保存的用户需求，不发送任务全部数据库、论文原文、目标答案或任意浏览器传入的文件路径。保存需求后，仅当管理员配置了客户端且还有额度时自动整理；未启用时只保存。再次整理需要明确操作，不会因刷新自动调用。服务器根据任务与版本派生请求 ID，重复操作不能重复派发。

网页可查看整理结果、原文引用和待明确问题。研究模式不要求论文标识；文献复现测试模式仍保留论文来源要求。用户不能通过网页更改模型、密钥或预算。此页面是操作者界面，不允许盲测主 Agent 访问。

运行入口的 `--model-ledger` 只接受已经存在的私人模型账本。未指定则无模型客户端；不能把路径拼错后自动新建空账本。当实际提供模型配置、明确数据上传范围及调用预算后，再由管理员初始化账本并通过服务端环境注入 `DEEPSEEK_API_KEY`。不从浏览器输入密钥，不复用开发者登录态，也不自动搜索其他项目密钥。

`ModelCalls(path, DeepSeekConfig(model_name), max_requests=0)` 可创建关闭调用的账本；正额度必须来自批准后的管理员配置。批准新的总预算须追溯原活动，不能为失败重新建账以隐藏成本。当前仅实现单账本内的不可重置计数，没有跨任意管理员新建数据库的全局限额。

## 验证与缺口

离线测试覆盖零额度、并发争抢最后额度、请求重放、重启、拒绝和超时、空/截断/非法 JSON、来源引用、完整事务、并发任务修改、研究模式无论文冻结和网页边界。浏览器在独立合成数据库上验证保存后自动整理、300 K 条件及原文、缺项问题、额度耗尽和刷新后的状态；没有真实模型请求。

仍需获批的真实能力测试、任务相关语义验证、条件摘要集中确认、文献工作台自动来源接入，以及主 Agent 规划、领域 Adapter、势函数选择、HPC 执行和分析。模型连接器不能被称为领域 Adapter 或产品自动计算已经完成。
