## 用户入口

新建任务默认选择科研计算，填写自然语言；任务名可省略。论文验证可从已登记文献进入，
保留完整标题、DOI、候选/待复现/复现中/已复现分类以及历史。当前尚无独立评分通过记录。
资源和帮助各有独立页面。模型未连接时明确保存需求，不宣称已经生成方案或提交计算。

结果标签包含总览、数据、曲线、结构、轨迹、报告和历史。结构与轨迹暂显示真实待接入状态，
不以示意模型替代模拟。普通研究已有 ResultsReader 结果也在主结果区域显示；参考结果只在
单独的人类操作者接口展示，不进入被测主 Agent 的生成输入。结果讨论是独立的人类操作者接口；用户主动发送时，可将当前可见结果交给自己配置的模型解读。

## 私有参考报告

管理员配置 `--reference-reports-directory` 与已有 `--ledger`，目录必须在 Git 外。
每个任务的固定子目录包含 `report.json` 和白名单声明的派生文件；报告绑定已选论文、
关联任务、参考角色评测、已结束且核算完成的请求、作业号和输入摘要。
报告引用已核验摘要的诊断结果和运行前 P 证据；网页的 A 值须与诊断值一致，P 值须与留存的论文指标一致。P-A 绝对差和百分比由后端
从明确的数值计算，不接受浏览器写分数。GET 不提交、分析或调用模型。

通过受信控制端 `PaperStore.bind_reference_evaluation` 关联 A 时，允许 B 条件尚未冻结；
只允许 reference 角色，保留原评测与次数，幂等重复不能转移关联。普通 B 绑定仍受原条件
冻结要求约束，不能使用此接口绕过。不存在浏览器参考绑定或发布报告端点。

本接口导入的是 Codex 辅助诊断证据，不替代自动 OutputCollector/AnalysisService 的验收，
不发布科学通过结论。读取验证文件身份、大小和摘要，拒绝符号链接、未声明文件和非有限
数值；下载只返回再次校验过的文件字节，不公开服务端路径。

## 模型连接和结果讨论

选择 DeepSeek、GLM、Claude、GPT，并填写具体模型 ID。独立的 `/api/model-connections`
只接收写入的密钥，响应仅返回是否已配置；文件仅当前系统用户可读，处于私有数据目录。
不使用浏览器存储，不在任务历史、错误响应中回显密钥。可以移除密钥，保留无密钥操作历史。
原 `/api/model-preference` 仍只保存偏好。保存连接不会修改旧任务或发起模型请求。

用户主动读取目录时，DeepSeek、Claude、GPT 通过官方模型目录接口获取 ID；GLM 暂手动填写。
目录中的型号不等于通过科研工作流能力验收。官方协议依据：
[DeepSeek](https://api-docs.deepseek.com/api/list-models/)、
[Claude](https://platform.claude.com/docs/en/api/models/list)、
[OpenAI](https://developers.openai.com/api/reference/resources/models/methods/list)、
[GLM](https://docs.bigmodel.cn/api-reference/模型-api/对话补全)。

管理员以 `--enable-result-assistant` 启用独立结果讨论。用户发送问题后，服务固定所选
提供方和模型，保存不可覆盖的请求与上下文摘要，再请求解读当前已核验的结果。
已有请求 ID 不重复发送，未知/失败回执和令牌用量保留。模型不能写账本、执行代码或提交
HPC；此能力仅用于结果解读，自动执行新分析和绘图方案仍待接入。

第一周实际 B 仍为 Codex 辅助流程。四种结果讨论协议仅经合成响应检查，尚无用户密钥的
真实 API 验收。正式生成、修复和执行循环不能据此宣称已支持四种运行模型。

均读取当前记录。无来源的示意案例、数量和联系方式不出现在产品中。

当前 Codex 线程已按用户要求设置 15 分钟检查 B 的自动跟进。它不是产品后台监控验收。
产品应复用持久跟进服务，定时查询调度器、断线退避、重启恢复、终态核算并去重通知，
不依赖网页常开，不用大模型轮询，不用模型请求或模拟试运行检查状态。网页每 30 秒只
刷新本地已核验记录；不会因此新提交或查询超算。现有单任务后台监控已由独立进程跟进真实 B，并完成本机监督重启验收；历史显示最近检查时间，超期显示更新延迟。常开服务器长期部署及真实终态处理仍待验收。

B 次数来自同一任务的真实 agent 评测账本，不由报告固定填写；不可读时显示未知。
A 关联不把其他任务显示为已计算。任务修改历史与真实 A/B 提交历史均可从主结果区查看。
