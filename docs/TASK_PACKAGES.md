# 计算任务与参考资料导出

关联 Issue #17。冻结条件后，工作台“计算任务与参考资料”可分别下载两个 JSON 文件。它们是操作者准备资料，不是已经获准交给主 Agent 的盲测任务。

- 计算任务草稿：自动整理选定条件及自然语言任务文字，只复制值、单位和适用性。剔除论文标识字段、原始标题与描述、来源位置、其他候选、冲突解释及 CSV 原文。
- 参考准备资料：保留完整冻结审阅记录、选定候选与来源映射、条件记录和任务草稿的摘要。代码补充条件有独立标记；P、A、B 均为空，参考资格为未核验。

导出使用冻结记录并检查其摘要。相同记录与生成器版本导出相同字节，不修改条件修订或提交次数。更换生成器后应保存新旧产物及版本，不能拿新导出覆盖旧评测输入。

该投影仅按字段取值，不判断条件文字本身是否含目标数值、作者脚本或可检索答案的链接。草稿明确保留 `operator_review_required`，输入语义、资源完整性、运行隔离均未验证，也不授权执行。测试特意保留“答案写进条件值”的反例，防止把字段分离误称为语义隔离。

两个下载接口均属于本机操作者页面。主 Agent 不得访问此页面、任务数据库或参考下载接口。真实任务进入生成端前仍需核验输入内容、允许资源清单和系统访问隔离；这些不能靠隐藏一个网页按钮实现。

验证覆盖合成来源和答案标记不进入投影、所选条件完整性、单位与不适用原因、配对摘要、重启后导出一致性、本机接口与未冻结拒绝。本轮没有真实论文导出验收、模型调用或目标计算。
