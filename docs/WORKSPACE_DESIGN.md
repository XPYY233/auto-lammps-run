# Research workspace design — Issue #109

Authority: approved home layout and completed frontend, materials-science and visual audits.
Palette: background #F7FAFE; paper #FFFFFF; primary #0964F5; selected #EAF2FF; ink #13213A; secondary #51627D; borders #E2EAF4.
Type: system Chinese sans-serif; page title 30/40, section title 18/26, body 14/23, supporting text at least 13px. Numeric tables retain tabular figures.
Layout: one 64px top navigation; compact natural-language entry; aligned main column and 288px information rail. Results lead with the actual curve and a separate metric table; file groups keep provenance and original names.
Principles: distinguish loading, empty, error and retained evidence; distinguish computation from scientific acceptance; no invented counts, structures, pictures or results. Resource matching is not scientific applicability.

First delivery fixes result-refresh consistency and existing-result readability. The complete figure-target selection workflow and scientific structure/trajectory viewing remain separate unfinished items, not implied by these styles.

Potential resources are grouped by verified binding, element selection and exact companion file set. The file-level names, source links and hashes remain in details; missing companions are never reported as ready.
